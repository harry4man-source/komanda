# Komanda

A polished, mobile-first prototype for managing amateur sports teams.

## Features

- Match dashboard and attendance
- Interactive visual 5-a-side teamsheet
- Player ratings and player-of-the-match voting
- Persistent team message board
- Event calendar with RSVPs
- Editable player profile
- Installable PWA manifest

## Run locally

npm install
npm run dev

Build with npm run build. This prototype stores changes in localStorage; production would add authentication, a shared database, notifications, and team permissions.
